# Base64 Right-Click Decoder

웹페이지에서 보이는 base64 / URL / HTML / hex 문자열을 **페이지 위에서 바로 디코드**하고, 결과를 링크로 열거나 이미지 미리보기, 복사까지 — 별도 디코더 사이트 접속 없이 해결하는 크롬 확장 프로그램입니다.

## 기능

- **우클릭 → "Decode → Open Link"**: 선택 텍스트의 포맷을 자동 감지해 디코드하고, 결과가 URL이면 **새 탭에서 바로 열어줍니다.**
- **우클릭 → "Decode → Copy Result"**: 디코드 결과를 화면 오버레이 패널로 보여주고 복사 버튼 제공.
- **멀티 포맷 자동 감지**: base64, URL 인코딩(`%20`), HTML 엔티티(`&amp;`), hex — 포맷을 직접 고를 필요 없이 자동 판별.
- **바이너리 안전 처리**: base64/hex 디코드 결과가 텍스트가 아닌 바이너리면 에러 대신 **hex 덤프**로 보여줍니다.
- **이미지 미리보기**: 디코드 결과가 `data:image/...` URL이면 페이지 위에서 바로 이미지를 렌더링.
- **선택 툴팁**: 인코딩된 텍스트를 드래그 선택만 해도 결과가 툴팁으로 즉시 표시 (열기/복사/자세히 버튼 포함).
- 줄바꿈·공백, URL-safe base64(`-` `_`), 누락된 패딩까지 자동 처리.
- 전부 로컬에서 동작. **데이터 수집 없음, 분석 없음, 원격 코드 없음.**

## 설치 (개발자 모드)

1. `chrome://extensions` 접속
2. 우측 상단 **개발자 모드** ON
3. **"압축해제된 확장 프로그램을 로드합니다"** 클릭
4. 이 폴더 선택 → 완료

## 사용법

아무 페이지에서나:

- **드래그 선택**만 해도 (예: `aHR0cHM6Ly93d3cuZ29vZ2xlLmNvbQ==`) **툴팁**으로 디코드 결과가 자동 표시됩니다.
- 또는 선택 후 **우클릭**:
  - **Decode → Open Link** — 새 탭에서 `https://www.google.com` 열림
  - **Decode → Copy Result** — 복사 버튼과 함께 결과 표시

## 프로젝트 구조

```
manifest.json   # MV3 매니페스트 — 권한 + content_scripts
decode.js       # 공용 디코드/감지 로직 (base64/URL/HTML/hex, 바이너리→hex)
background.js   # 서비스 워커 — 우클릭 메뉴 + 결과 오버레이
content.js      # 콘텐츠 스크립트 — 선택 툴팁 + 오버레이
icons/          # 16 / 48 / 128 px 아이콘
```

## 권한 & 프라이버시

| 권한 | 용도 |
|------|------|
| `contextMenus` | 우클릭 디코드 메뉴 추가 |
| `activeTab` | 사용자가 확장을 실행한 순간 활성 탭에만 임시 접근 |
| `scripting` | 활성 페이지에 결과 오버레이 주입 |
| `content_scripts` (전체 페이지) | 선택 툴팁 — 툴팁을 위해 모든 페이지의 텍스트 선택에 접근 |

툴팁 때문에 Chrome에서 **"모든 웹사이트의 데이터 읽기 및 변경"** 경고 문구가 표시됩니다. 백그라운드 브라우징 없음, 데이터 수집 없음, 원격 코드 없음 — 툴팁은 사용자가 드래그 선택한 텍스트만 읽으며, 모든 동작은 사용자의 명시적 동작에 의해서만 실행됩니다.
