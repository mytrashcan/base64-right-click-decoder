# Base64 Right-Click Decoder

웹페이지에서 보이는 base64 문자열을 **페이지 위에서 바로 디코드**하고, 결과 링크에 별도 디코더 사이트 접속 없이 바로 접속하는 크롬 확장 프로그램입니다.

## 기능

- **우클릭 → "Base64 디코드 → 링크 열기"**: base64를 선택해 디코드하고, 결과가 URL이면 **새 탭에서 바로 열어줍니다.**
- **우클릭 → "Base64 디코드 → 결과 복사"**: 디코드 결과를 화면 오버레이 패널로 보여주고 복사 버튼 제공.
- 줄바꿈·공백, URL-safe 문자(`-` `_`), 누락된 패딩까지 자동 처리.
- 전부 로컬에서 동작. **데이터 수집 없음, 분석 없음, 원격 코드 없음.**

## 설치 (개발자 모드)

1. `chrome://extensions` 접속
2. 우측 상단 **개발자 모드** ON
3. **"압축해제된 확장 프로그램을 로드합니다"** 클릭
4. 이 폴더 선택 → 완료

## 사용법

아무 페이지에서나 base64 문자열을 **드래그 선택** (예: `aHR0cHM6Ly93d3cuZ29vZ2xlLmNvbQ==`) → **우클릭**:

- **Base64 디코드 → 링크 열기** — 새 탭에서 `https://www.google.com` 열림
- **Base64 디코드 → 결과 복사** — 디코드 결과를 복사 버튼과 함께 표시

## 프로젝트 구조

```
manifest.json   # MV3 매니페스트 — 권한: contextMenus, activeTab, scripting
background.js   # 서비스 워커 — 우클릭 메뉴 + 디코드 로직 + 결과 오버레이
icons/          # 16 / 48 / 128 px 아이콘
```

## 권한 & 프라이버시

| 권한 | 용도 |
|------|------|
| `contextMenus` | 우클릭 디코드 메뉴 추가 |
| `activeTab` | 사용자가 확장을 실행한 순간 활성 탭에만 임시 접근 |
| `scripting` | 활성 페이지에 작은 결과 오버레이 주입 |

백그라운드 브라우징 없음, 데이터 수집 없음, 원격 코드 없음 — 모든 동작은 사용자의 명시적 우클릭에 의해서만 실행됩니다.
